# Crypto Card Lifecycle Registry

Historical registry of crypto card programs and their underlying payment infrastructure.

## Scope

This project records the lifecycle of crypto card programs, infrastructure providers, their relationships, material incidents, and supporting evidence.

It is not a card ranking site and does not rate products for investment or safety.

## Core record layers

- program
- provider
- relation
- event
- evidence

## Canonical safety rule

Unreviewed research and monitoring output must not be written directly into canonical records. New or changed records require evidence-backed review before publication.
