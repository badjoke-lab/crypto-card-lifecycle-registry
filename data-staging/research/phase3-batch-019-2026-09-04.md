# Phase 3 batch 019 research — 2026-09-04

Bounded candidate set:
1. Ripio Card
2. Buenbit Mastercard
3. belo Mastercard

## Ripio Card

Accepted.

First-party / infrastructure evidence reviewed:
- Ripio current card terms: https://terms.ripio.com/ar/ripio-card-digipayments
  - Current Argentina prepaid card offered by Ripio.
  - Co-issued by Digipayments S.A.U. and Pomelo Fintech Services S.A.S.
  - Visa network.
  - Card spending uses available fiat funds resulting from sale of the selected digital asset in the user's Ripio account.
- Ripio current product article: https://launchpad.ripio.com/notas-de-la-app/ripio-card
  - Current physical and virtual Visa prepaid card; user selects crypto or pesos for payment.
- Pomelo launch statement: https://pomelo.la/blog/ripio-tarjetas-pomelo
  - Argentina launch for virtual Ripio crypto cards on 2023-02-08.
  - Pomelo states it provides card issuance/processing infrastructure and later physical-card manufacturing/distribution.

Decision:
- Add active Ripio Card program.
- Add Digipayments S.A.U. provider as issuer.
- Add Pomelo Fintech Services S.A.S. provider as issuer + processor because current Ripio terms explicitly say co-issued and Pomelo describes its issuing/processing role.
- Add Visa network relation.
- Add 2023-02-08 Argentina launch event.

## Buenbit Mastercard

Accepted.

First-party / network evidence reviewed:
- Buenbit current prepaid-card terms: https://buenbit.com/ar/tyc/terminos-y-condiciones-tarjetas
  - Mastercard prepaid cards issued and managed by BKR ARGENTINA S.A.
  - BKR is explicitly identified as the card issuer.
- Buenbit help collection: https://ayuda.buenbit.com/ar/es/collections/7617561-tarjeta-buenbit-mastercard
  - Current virtual/physical Mastercard card program and operational support.
- Mastercard launch/relaunch statement: https://www.mastercard.com/news/latin-america/es/sala-de-prensa/comunicados-de-prensa/pr-es/2022/octubre/buenbit-relanza-su-tarjeta-mastercard-con-una-propuesta-superadora/
  - 2022-10-06 relaunch in Argentina.
  - Crypto is converted instantly to pesos for purchases.
  - Pomelo identified as strategic infrastructure partner for the 2022 generation.

Decision:
- Add active Buenbit Mastercard program.
- Add BKR ARGENTINA S.A. provider as issuer.
- Reuse new Pomelo provider as processor/provider for the evidenced 2022 generation.
- Add Mastercard relation.
- Add 2022-10-06 relaunch event rather than claiming this was the product's original launch.

## belo Mastercard

Accepted.

First-party / network evidence reviewed:
- Current belo card page: https://www.belo.app/ar/belo-mastercard
  - Current Argentina prepaid Mastercard; user can spend pesos or supported digital currencies; merchant receives local currency.
- Current belo help: https://help.belo.app/es/articles/5650348-la-tarjeta-belo-mastercard
  - Current local prepaid Mastercard, physical/virtual, Argentina eligibility and crypto/fiat spending behavior.
- Mastercard launch statement: https://www.mastercard.com/news/latin-america/es/sala-de-prensa/comunicados-de-prensa/pr-es/2022/febrero/belo-lanza-hoy-al-mercado-la-tarjeta-prepaga-belo-mastercard-en-argentina/
  - 2022-02-21 launch of the first 1,000 prepaid belo Mastercard cards in Argentina.
  - Explicit crypto-to-fiat conversion model.

Decision:
- Add active belo Mastercard program.
- Add Mastercard network relation.
- Add 2022-02-21 Argentina launch event.
- Do not add an issuer relation from secondary/inferred issuer claims. Current first-party evidence reviewed for this batch does not clearly identify the regulated issuer.

## Rejected / unresolved claims

- No issuer is inferred for belo Mastercard from third-party card directories.
- Ripio co-issuer roles are recorded only because the current Ripio terms explicitly name both Digipayments and Pomelo as co-issuers.
- Buenbit's BKR issuer role is current; the 2022 Pomelo partnership is treated as infrastructure evidence and not used to replace the current issuer.
